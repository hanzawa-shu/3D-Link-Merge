# 3D連結マージ デモ

ぷよぷよ／1024（同色連結）／スイカゲームの要素を組み合わせた、3Dグリッド積み上げ型パズルゲームのブラウザデモ。

詳しいルール・設計は [仕様書.md](./仕様書.md) / [設計書.md](./設計書.md) を参照。

## 起動方法

npmやビルドツールは使用していないため、以下の手順だけで動作する。

1. ターミナルでこのディレクトリ（`Demo_1`）に移動する
   ```
   cd /Users/hanzawashu/Projects/web-apps/games/Demo_1
   ```
2. 開発用サーバーを起動する（Python3が入っていれば追加インストール不要）
   ```
   python3 dev-server.py 8734
   ```
3. ブラウザで以下を開く
   ```
   http://localhost:8734
   ```

`index.html` を直接ブラウザで開く（`file://`）ことはできない。ES Modulesの読み込みにはHTTP経由でのアクセスが必要なため。

### なぜ `python3 -m http.server` ではなく `dev-server.py` を使うのか

標準の `python3 -m http.server` はキャッシュ制御ヘッダーを送らないため、Chrome等が
ESモジュール（`.js`）を積極的にキャッシュし、**ファイルを編集しても通常のリロードでは
古いコードが実行され続ける**（「直したのに反映されない」の原因になる）。

`dev-server.py` は全レスポンスに `Cache-Control: no-store` を付けて常に最新ファイルを
再取得させる。標準サーバーを使ってしまった場合は、ブラウザでハードリロード
（Mac: `Cmd + Shift + R` / Win: `Ctrl + Shift + R`）すれば最新コードを読み込める。

## 終了方法

サーバーを止めたい場合は、起動したターミナルで `Ctrl + C`。バックグラウンドで起動した場合は、該当プロセスを `kill <PID>` で終了する（`lsof -nP -iTCP:8734 -sTCP:LISTEN` でPIDを確認できる）。放置しても外部に公開されるものではないため害はない。
